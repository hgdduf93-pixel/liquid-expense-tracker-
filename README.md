# 💳 Mudrix by gsd

An intelligent Android expense management app powered by **Google Gemini AI**. It automatically parses transaction notifications and bank alerts to track, categorize, and summarize your daily spending in real time.

---

## ✨ Features

- 🤖 **AI-Powered Parsing:** Automatically extracts amount, merchant, and category from incoming bank SMS/notifications using Gemini AI.
- 📊 **Smart Categorization:** Automatically classifies expenses into Food, Travel, Bills, Shopping, and more.
- 🔒 **Privacy Focused:** Operates without storing personal banking credentials or sending sensitive account info to third-party databases.
- ⚡ **Lightweight & Fast:** Native Android performance with minimal battery and memory overhead.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Platform:** Android SDK
- **AI / LLM:** Google Gemini API (Google AI Studio)
- **Architecture:** Modern Android Architecture (MVVM)
- **Build System:** Gradle (Kotlin DSL - `.gradle.kts`)

---
